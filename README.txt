- javascript/ (contém script.js)
- assets/

Imagens já incluídas:
- assets/logo-show-english.png
- assets/teacher-hero.png
- assets/teacher-about.png

Vídeos:
Coloque seus depoimentos na pasta assets usando exatamente estes nomes:
- testimonial-01.mp4
- testimonial-02.mp4
- testimonial-03.mp4

Para abrir o site:
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Para publicar, envie toda a pasta para sua hospedagem.

Observação:
teacher-about.png usa a mesma imagem da campanha como placeholder.
Você pode substituir por outra foto mantendo o mesmo nome do arquivo.
